Instructions de Configuration

⚡ Configuration Rapide (Terminal)

Utilisez le script de configuration VPN pour une installation automatisée :

Terminal - Configuration VPN
cd /opt/mediahub
./scripts/setup-vpn.sh
💡 Conseil : Le script setup-vpn.sh vous guidera à travers un assistant interactif pour configurer votre VPN, même si vous n'avez aucune expérience technique.

🔧 Configuration Manuelle (.env)

Pour les utilisateurs avancés, vous pouvez éditer directement le fichier .env :

# Configuration VPN VPN_SERVICE_PROVIDER=protonvpn VPN_TYPE=openvpn # Pour OpenVPN (la plupart des fournisseurs) OPENVPN_USER=votre_username OPENVPN_PASSWORD=votre_password SERVER_COUNTRIES=Netherlands # Pour Wireguard (Mullvad, AirVPN, etc.) WIREGUARD_PRIVATE_KEY=votre_cle_privee WIREGUARD_ADDRESSES=10.64.0.1/32

🔍 Dépannage VPN

Le VPN ne se connecte pas

Vérifiez vos identifiants dans le fichier .env
Consultez les logs : docker logs gluetun
Redémarrez le conteneur : docker compose restart gluetun

Tester la connexion

Vérification IP
docker exec gluetun wget -qO- https://ipinfo.io/ip
⚠️ Important : Ne partagez jamais vos identifiants VPN. Utilisez toujours les identifiants de service (OpenVPN/IKEv2), pas vos identifiants de compte.
